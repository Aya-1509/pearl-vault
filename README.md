# Pearl Vault – Jewellery Landing Page

## Project Description
Pearl Vault is a fictional jewellery brand featuring a modern and elegant landing page. The design showcases jewellery collections through a clean layout, attractive visuals and a premium colour palette.

## Target Audience
Young adults, jewellery lovers and customers looking for stylish accessories.

## Tools Used
- Figma
- Auto Layout
- Reusable Components

## Main Features
- Header and Navigation
- Hero Section
- Featured Jewellery Collection
- About Us Section
- Why Choose Us
- Promotional Banner
- Footer

## Responsive Design
- Desktop: 1440px
- Mobile: 390px
